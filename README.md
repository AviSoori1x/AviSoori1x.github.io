# avisoori1x.github.io

Personal site for Avinash Sooriyarachchi. Static HTML generated by a small Python
script and served directly by GitHub Pages (`.nojekyll` stops Pages from running
Jekyll over the output).

## Build

```sh
python -m venv .venv && .venv/bin/pip install markdown pygments pyyaml jinja2
.venv/bin/python build.py            # write the site
.venv/bin/python build.py --serve    # write it, then serve on :8000
```

Commit the generated files at the repo root — that is what Pages serves.

## Layout

| path                | what it is                                                           |
| ------------------- | -------------------------------------------------------------------- |
| `_src/data/*.yml`   | all site content: profile, projects, talks, writing, media, timeline |
| `_src/templates/`   | Jinja2 templates                                                     |
| `_src/css/main.css` | the whole design system                                              |
| `_posts/*.md`       | blog posts, markdown, `YYYY-MM-DD-Name.md`                           |
| `build.py`          | the generator                                                        |

Everything else at the root is generated output.

## Adding a post

Drop a markdown file in `_posts/` named `YYYY-MM-DD-Title_Here.md`, starting with
an `# H1` that is the title, and run the build.

`build.py` reproduces the permalink scheme of the original Jekyll site
(`/YYYY/MM/DD/<name>.html`, where `:` and spaces become `-` and everything else is
preserved verbatim), so the URLs of the seven migrated posts are unchanged and no
inbound link breaks. `_src/data/posts.yml` pins their exact historical titles.

## Adding content to the front page

Edit the relevant file in `_src/data/` and rebuild. Nothing on the front page is
hard-coded in a template.
